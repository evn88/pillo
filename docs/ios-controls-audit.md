# Ревизия элементов управления — 14 сентября 2026

## Правила

Проверена текущая реализация всех экранов и семи модальных форм. Liquid Glass используется для навигации и панелей действий; поля, карточки и группы выбора сохраняют непрозрачные поверхности. Это соответствует разделению содержимого и управления у Apple, а не требованию делать стеклянным каждый элемент.

- Панели форм: нативные SwiftUI Button, `glass` для закрытия, `glassProminent` для подтверждения, системная роль `cancel`, единый размер `large`. На старом iOS — стандартные bordered styles.
- В содержимом: второстепенные bordered-кнопки, явные подписи действий и выбранных значений. Для очевидного возврата отметки — круглая кнопка `arrow.uturn.backward` справа, с полным доступным именем.
- Области управления не менее 44 pt; длинные панели допускают перенос, контент прокручивается, основные действия остаются сверху.
- Поля используют системную клавиатуру, десятичный ввод для количества, явные labels и ошибки. Даты, время, лекарственная форма и тема используют нативные пикеры iOS.
- При сохранении отключены повторная отправка, закрытие и редактирование значений. Ошибка не закрывает форму; успешная команда закрывает её.
- При смене вкладки временное содержимое размонтируется, клавиатура закрывается. Свайпы, черновики модальных форм, поиск, пагинация и прокрутка начинаются заново при возвращении. Данные остаются в провайдере и хранилище.

## Инвентаризация

Поиск JSX-элементов управления выполнен по `app` и `src`, исключены тесты. Проверены также обёртки экранов и общие компоненты.

| Область / файлы | Результат ревизии |
| --- | --- |
| `native-action-button`, `ui` | Общие toolbar/icon-only/semantic-role параметры; системное disabled-оформление; fallback для старого iOS и Android |
| `pillo-shell` и четыре маршрута | Сброс временного интерфейса через реальный focus маршрута; регрессионный тест ухода и возврата |
| `glass-tab-bar`, `screen-actions` | Нативные стеклянные поверхности, именованные иконки, selected-state, плюс скрыт в настройках; поведение сохранено |
| `today-screen`, `intake-action` | Отмена перенесена вправо, убрана отдельная строка длинной кнопки; обычный приём сохраняет одно нажатие |

## Проверки и границы доказательств

- TypeScript, ESLint, 107 тестов / 24 файла и iOS Release build проходят.
- iPhone 17 Pro, iOS 26.5, тёмная тема: раскрытие через accessibility action → переход → возврат проверены на «Сегодня», «Препаратах», «Расписании». Все карточки закрыты; данные не изменены.
- Визуально проверены добавление препарата, расписание, вложенный выбор препарата, ручной приём, история и редактор фактической дозы; закрытие без сохранения. Кнопки не перекрывают поля.
- Снимки: `/private/tmp/pilldan-schedule-controls-20260914.png`, `/private/tmp/pilldan-dose-controls-20260914.png`.
- Физический свайп, VoiceOver-жесты, программная клавиатура, увеличенный Dynamic Type, Reduce Motion/Transparency, светлая тема, iPad, Android и iOS 27 в этой итерации не прошли полный визуальный прогон. Нельзя считать эту ревизию полной сертификацией соответствия HIG на всех устройствах.
- Реальные приёмы, остатки и расписание для проверки не изменялись. Кнопка отмены проверена компонентным тестом. Редкий лист возврата старой записи проверен по коду; визуально не проверен, реальная запись не отменялась.
