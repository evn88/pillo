## Изменения в приложении и совместимость

- Видимое имя, пользовательские тексты, заголовок уведомлений, актуальная документация и имена графических ресурсов используют PillDan.
- Основная схема ссылок — `pilldan://`; `pillo://` остаётся совместимым псевдонимом.
- `com.vershkov.pillo`, локальная база `pillo.db`, ключи хранилища, канал и идентификаторы уведомлений сохраняются, чтобы обновление продолжало работать с установленным приложением и его данными.
- Уведомления со старым заголовком требуют перепланирования при следующей синхронизации расписания. Уже доставленные уведомления автоматически не переименовываются.
- Исторические OpenSpec-документы, внутренние имена модулей и native target Pillo сохраняются. Это не пользовательский бренд.
- Для изменения подписи под иконкой и регистрации новой схемы нужна новая нативная сборка. Локальные сгенерированные iOS/Android-файлы синхронизированы, но игнорируются Git; источником конфигурации остаётся `app.json`.

## Проверка реализации

`npm run type-check`, `npm test` (23 файла, 105 тестов), `npm run lint` завершились успешно. `npx expo install --check` завершился успешно по локальной таблице зависимостей; сетевой справочник недоступен, поэтому актуальность версий онлайн не подтверждена. Expo public config подтверждает имя, обе схемы, прежние идентификаторы и существование всех ресурсов. Нативная пересборка и проверка на устройстве в рамках переименования не выполнялись.
